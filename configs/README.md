# How to configure the YAML templates

For each sub-directory, there are two folders:

1. ```base_template```

    This is where the basic YAML file exists for each type of job.
    Because the fields are incomplete, the user will have to copy the YAML files
    into the ```user``` directory and modify according to their needs.

2. ```user```

    This is a sandbox directory where the user may store the modified YAML files.
    I have taken the liberty of uploading my personal modifications to this directory,
    since this is my repository.
